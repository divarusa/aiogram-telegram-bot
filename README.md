# Telegram Bot with aiogram

A modular Python Telegram bot using the `aiogram` framework, built-in Finite State Machine (FSM), and SQLite integration.

## Features

- **FSM (Finite State Machine):** State management for step-by-step user interactions
- **Modular Architecture:** Command handlers organized in a dedicated directory
- **Database Integration:** SQLite for persistent data storage and execution of custom SQL queries
- **Configuration Management:** Centralized environment and bot settings configuration

## Tech Stack

- Python 3
- aiogram
- SQLite3
